# C Projects

A collection of C programming projects developed to strengthen my understanding of **C programming, data structures, memory management, file handling, pointers, and system-level programming** through hands-on implementation.

## Projects

### 1. Steganography

A C-based **BMP image steganography** project that hides secret file data inside an image using **Least Significant Bit (LSB) encoding**.

**Topics Covered:**

* File Handling in C
* BMP Image Processing
* Bit Manipulation
* LSB Encoding and Decoding
* Pointers
* Structures
* Memory Management
* Command-Line Arguments
* Modular Programming

📁 [Open Steganography Project](./Stegnography/)

---

### 2. APC – Arbitrary Precision Calculator

A C-based **Arbitrary Precision Calculator** implemented using **linked lists** to perform arithmetic operations on numbers larger than the standard C data types can handle.

The project represents each digit as a node in a linked list and implements arithmetic operations using linked-list manipulation.

**Operations:**

* Addition
* Subtraction
* Multiplication
* Division
* Modulus

**Topics Covered:**

* Singly Linked Lists
* Dynamic Memory Allocation
* Pointers and Double Pointers
* Linked List Traversal
* Carry and Borrow Handling
* Arithmetic Algorithms
* Modular Programming
* Command-Line Arguments

📁 [Open APC Linked List Project](./APC_linkedlist/)
